블로그를 몇 번이나 만들다가 지웠습니다. 이번에는 다르게 해보려고 합니다. 글을 쓰는 일과 코드를 만드는 일을 같은 공간에 두는 것. 그래서 이 사이트는 거창한 플랫폼이 아니라 **한 권의 공책**에 가깝습니다.

## 왜 또 블로그인가

기록을 남기는 방식은 많습니다. 노션, 깃허브 이슈, 메신저의 나에게 보내기. 그런데 오래 남는 글을 쓰기에는 이상하게도 블로그만 한 것이 없더군요.

이 공책에 남길 것은 세 가지입니다.

- 만들면서 배운 것
- 부수면서 알게 된 것
- 다시 만들면서 달라진 생각

## 어떻게 만들었나

Solid 2.0과 Vite, 그리고 Cloudflare Pages를 씁니다. 글은 `contents/posts` 폴더의 마크다운 파일이고, 빌드할 때 HTML과 검색 인덱스가 함께 만들어집니다.

```bash
npm run dev     # 글을 쓰면서 바로 확인
npm run build   # HTML, RSS, sitemap, 검색 인덱스 생성
```

빌드 결과물은 정적 파일뿐이라 서버가 필요 없습니다. 글을 커밋하면 Cloudflare가 알아서 배포합니다.

## 앞으로

완성된 글만 올리지는 않을 생각입니다. 짧은 메모, 실패한 실험, 읽는 중인 책의 구절도 함께 남기려고 합니다. 정돈되지 않은 기록이 쌓이다 보면 언젠가 하나의 지도가 되지 않을까요.
